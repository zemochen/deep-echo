# 快速开始指南

## 项目概览

DeepEcho前后端分离架构重构项目。将单体Python应用重构为三层架构：React前端 + Tauri中间层 + Python后端。

## 📁 文件结构

```
.kiro/specs/frontend-backend-separation/
├── requirements.md              # 12个需求文档
├── design.md                    # 详细设计文档
├── tasks.md                     # 28个实现任务
├── AUDIO_CAPTURE_ANALYSIS.md    # 音频采集分析
├── SUMMARY.md                   # 项目总结
└── QUICK_START.md              # 本文件
```

## 🎯 核心信息

### 技术栈
- **前端**: React 18 + Material-UI + TypeScript
- **中间层**: Tauri + Rust
- **后端**: Python (现有代码)

### 架构
```
前端 (React + MUI)
  ↓ Tauri命令
中间层 (Tauri + Rust)
  ↓ IPC通信
后端 (Python)
```

### 关键特性
- ✅ 完整的音频采集 (mic + speaker)
- ✅ 实时数据推送
- ✅ 跨平台支持 (Windows + macOS)
- ✅ 现有代码复用
- ✅ 自动故障恢复

## 📋 需求概览

### 12个主要需求

1. **前端用户界面** - 转录显示、响应显示、控制面板
2. **Tauri命令层** - 前后端通信、异步处理、事件监听
3. **通信协议** - 命令定义、数据模型、JSON序列化
4. **后端服务** - 音频处理、转录、AI响应、配置管理
5. **音频采集** - 麦克风、扬声器、设备管理
6. **系统资源访问** - 文件操作、设备管理、权限控制
7. **实时数据推送** - 事件系统、消息可靠性
8. **错误处理** - 异常捕获、日志记录、自动恢复
9. **配置管理** - 配置文件、参数验证、预设支持
10. **跨平台兼容性** - Windows和macOS支持
11. **性能优化** - 响应时间、资源使用、长期稳定性
12. **开发和部署** - 构建脚本、文档、CI/CD

## 🏗️ 设计要点

### 系统架构
- 三层分离: 前端、中间层、后端
- 前后端通过Tauri命令通信
- 后端通过事件系统推送数据到前端
- 支持异步处理和错误恢复

### 通信协议
- **前端命令**: start_recording, stop_recording, get_transcript等
- **后端事件**: transcript-updated, response-generated, status-changed等
- **数据格式**: JSON序列化

### 音频采集
- **麦克风**: sr.Microphone (所有平台)
- **扬声器**: WASAPI (Windows) / BlackHole (macOS)
- **设备管理**: 动态设备选择和切换
- **故障恢复**: 自动设备恢复机制

## 🔍 关键概念

### Tauri命令
前端通过Tauri命令调用后端功能的方式。例如:
```typescript
invoke('start_recording', { device_type: 'microphone' })
```

### 事件系统
后端通过事件系统推送数据到前端的方式。例如:
```typescript
listen('transcript-updated', (data) => {
  // 处理转录更新
})
```

### IPC通信
Tauri中间层与Python后端之间的进程间通信。

### 正确性属性
系统应该满足的10个正确性属性，用于验证系统行为。
